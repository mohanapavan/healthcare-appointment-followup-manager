# Image credits

All photography is sourced from [Pexels](https://www.pexels.com), free for
commercial use with no attribution required. Credits are listed here anyway, as
a matter of practice. Each file was downloaded, cropped, and re-encoded to
`.webp` locally (see the old `_imgtool.mjs` in git history) — nothing is
hotlinked, and no placeholder service is used. A uniform grade
(`~88%` saturation, slight warmth, held-back contrast) is applied in CSS via the
`.img-grade` wrapper so the set reads as one system.
